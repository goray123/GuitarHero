Modified for this project using fontTools: instantiated weight 700, retained
ASCII, Hangul Jamo, Hangul Compatibility Jamo and all modern Hangul syllables,
and renamed the font to Boss Title KR. Font data is bundled in player builds
so the Korean boss name does not depend on fonts installed on the device.
