# 보스 1 개발 안내

## 실행

Assets/Scenes/Boss1_Arena.unity를 열고 Play를 누릅니다.
보스전 전용 씬에서 기존 Player 프리팹과 Boss1 프리팹을 생성합니다.

- 좌우 방향키: 이동
- 위 방향키: 점프
- 아래 방향키: 슬라이드
- Z: 기본 공격
- A: 코드 스트라이크
- R 또는 결과창의 RETRY: 보스전 재시작
- 테스트 전용 B: 보스에게 3초 바인드
- 테스트 전용 F2: 보스 체력을 50%로 내려 2페이즈 전환 예약

테스트 키는 씬의 Boss1Arena > Enable Test Keys를 끄면 비활성화됩니다.
시작 씬은 기존 설정을 유지하고, 보스전 씬을 빌드 목록에 추가했습니다.

## 구현한 전투

체력 50%를 경계로 2페이즈를 구성했습니다.
진행 중인 패턴과 후딜, 남은 미사일을 마친 뒤 전환합니다. 전환 중에도 피해를 받으며, 전환 자체로 난사를 추가하지 않습니다.

1페이즈에서는 3타, 부스터 돌진, 후방 미사일을 사용합니다.
2페이즈에서는 같은 본체 패턴과 속도를 유지하고 조준 고정 미사일 1발을 독립적으로 반복합니다.

난사는 두 페이즈에서 공통으로 반복합니다.
첫 예약은 전투 시작 20초 후이며, 이후에는 난사 후딜 종료 후 20초를 셉니다.
예약은 한 번만 보관하며, 페이즈 전환으로 타이머를 초기화하지 않습니다.
각 난사는 2발씩 3묶음, 총 6발입니다. 같은 묶음의 폭발 사이에는 플레이어 너비 + 0.2H 이상의 빈 공간을 남깁니다.

조준 고정 미사일은 0.9초 추적한 뒤 위치를 고정하고, 0.6초 후 폭발합니다.
추적 중에는 경고 원을 점멸시키고, 고정 후에는 굵은 원과 십자 표시를 켭니다.
공중의 플레이어도 지면을 조준합니다. 고정된 위치와 착탄 시각은 이후 변경하지 않습니다.
미사일에는 비행 접촉 피해가 없으며, 반경 0.4H의 폭발이 0.2초간 유효합니다.

3타 전체의 타격 시점을 먼저 예약합니다.
미사일 폭발과 본체 타격 사이에 0.35초 간격을 유지하도록 조준 또는 다음 본체 패턴의 시작을 늦춥니다.
바인드로 타격 시점이 이동했을 때도 이 간격을 다시 확인합니다.

바인드는 본체 동작과 난사 타이머를 정지하고, 미확정 조준을 취소합니다.
이미 고정된 미사일은 원래 시각에 처리합니다.
해제 후에는 0.35초의 예고를 두고 동작을 재개합니다.
보스 사망 시 남은 경고와 미사일을 즉시 정리하며, 플레이어 사망 시에도 전투를 종료합니다.

## 플레이어 연결

Player 프리팹에 PlayerHealth를 추가했습니다.

- 최대 체력 100
- 피해 수락 후 0.2초 무적
- 보스 휘두르기·펀치·미사일: 최대 체력의 6%
- 내려찍기·돌진: 최대 체력의 10%
- 피해가 실제 수락됐을 때 리듬 게이지의 NotifyBossDamageTaken을 한 번 호출
- 사망 시 이동·기본 공격·코드 스트라이크 정지

보스의 몸체는 플레이어를 밀거나 접촉 피해를 주지 않습니다.
슬라이드로 반대편으로 통과할 수 있으며, 기존 기본 공격과 코드 스트라이크는 Damageable 인터페이스로 보스에게 피해를 줍니다.
기본 공격으로 받은 피해 때문에 진행 중인 보스 패턴을 취소하지 않습니다.

## 스프라이트와 구조

- Assets/Prefabs/Boss1.prefab: 재사용할 보스 프리팹
- Boss1Sprites.asset: 12종 동작, 총 96개 Sprite 참조
- Boss1CombatModel.cs: 엔진과 분리된 상태·페이즈·미사일 스케줄러
- Boss1Controller.cs: 이동, 충돌 판정, 스프라이트 구간 재생
- Boss1MissileView.cs: 경고 원, 미사일 비행, 폭발과 경고음
- Boss1Arena.cs: 전용 씬, HUD와 재시작
- PlayerHealth.cs: 플레이어 체력과 사망

본체 Animator를 추가로 만들지 않고, 보스 컨트롤러가 기획의 예고·판정·후딜에 맞춰 시트의 포즈 구간을 재생합니다.
조준 미사일의 경고·비행·폭발은 별도 렌더러에서 진행하므로 본체 근접 애니메이션을 덮어쓰지 않습니다.
사망 시 Death_00~07을 재생한 뒤 마지막 포즈를 유지합니다.

## 조정과 확인

Boss1 프리팹의 Settings에서 체력, 공격 시간, 재사용 대기, 미사일 주기 등을 조정합니다.
기준 거리 H는 플레이어의 서 있는 BoxCollider2D 높이이며, 초기 보스 HP 1500은 프로토타입 값입니다.
실제 90~120초 전투 시간과 난이도는 직접 플레이하면서 조정해야 합니다.

검증 명령:

~~~powershell
.\Tools\ValidateBoss1.ps1
.\Tools\CompileBoss1Runtime.ps1
node Tools/VerifyBoss1Assets.cjs
.\Tools\ValidateBoss1Unity.ps1
~~~

ValidateBoss1은 전투 스케줄러를 직접 C#으로 컴파일해 실행합니다.
CompileBoss1Runtime은 설치된 Unity SDK의 실제 런타임 참조로 전체 Assets/Scripts를 컴파일합니다.
VerifyBoss1Assets는 스프라이트·프리팹·씬·빌드 참조를 검사합니다.
ValidateBoss1Unity는 Temp/Boss1UnityValidation의 복사 프로젝트에서 Play 모드와 실제 2D 판정을 검사합니다.
원본 프로젝트의 열려 있는 씬을 바꾸지 않습니다.

현재 검증 결과는 전투 모델 49/49, Unity Play 모드 23/23 통과입니다.
프리팹·씬·스프라이트 참조 291개 검사와 실제 Unity 런타임 어셈블리 기준 전체 C# 컴파일도 통과했습니다.
자세한 결과는 output/boss1-development에 보관했습니다.
