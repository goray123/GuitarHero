# Boss 1 스프라이트 v1

기획서의 컨셉아트를 바탕으로 내장 ImageGen으로 만든 1차 애니메이션용 스프라이트 세트입니다.
포즈를 생성한 뒤 완전한 포즈 단위로 추출하고, 크기와 발 기준점을 맞춰 투명 PNG 아틀라스로 패킹했습니다.
원본 캐릭터의 중장갑, 큰 주먹, 붉은 등 발사기 2개, 청록색 회로, 붉은 바이저를 유지했습니다.

전투 구현과 실행 방법은 [개발 안내](IMPLEMENTATION.md)에 있습니다.
Assets/Scenes/Boss1_Arena.unity를 열고 Play를 누르면 보스전을 시작합니다.

## 유니티에서 사용

이 폴더는 이미 현재 프로젝트의 Assets/Characters/Boss1에 들어 있습니다.
PNG와 같은 이름의 .meta를 함께 유지하면, 임포트 시 각 프레임의 이름과 SpriteRect를 사용할 수 있습니다.
Unity 6000.3.25f1에서 96개 스프라이트 임포트와 사망 애니메이션의 마지막 프레임 유지를 확인했습니다.

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Multiple
- Grid: 8열, 셀 256 × 256 px
- Offset / Padding: 0 / 0
- Pixels Per Unit: 100
- Mesh Type: Full Rect
- Filter Mode: Bilinear
- Compression: None
- Mip Maps: Off
- Max Size: 2048
- 본체 피벗: Custom (0.5, 0.125). 셀의 위에서 224 px 지점이 발 기준점입니다.
- 이펙트 피벗: Custom (0.5, 0.5)
- 기본 시선: 오른쪽. 왼쪽을 볼 때 SpriteRenderer.flipX를 사용합니다.

수동으로 다시 슬라이스할 때는 Sprite Editor > Slice > Grid By Cell Size에서 256 × 256을 지정합니다.
Support 시트의 3~4행은 슬라이스 후 피벗을 Center로 지정합니다.
각 동작의 이름은 Boss1_동작명_00부터 07까지이며, 왼쪽에서 오른쪽으로 재생합니다.

## Actions 시트

파일: Sprites/Boss1_Actions_v1.png
해상도: 2048 × 2048 px, 8열 × 8행, 총 64프레임.

| 위에서부터 행 | 동작 | 스프라이트 이름 |
| --- | --- | --- |
| 1 | 대기 | Boss1_Idle_00 ~ 07 |
| 2 | 이동 | Boss1_Walk_00 ~ 07 |
| 3 | 1타: 하단 휘두르기 | Boss1_LowSweep_00 ~ 07 |
| 4 | 2타: 중앙 펀치 | Boss1_MidPunch_00 ~ 07 |
| 5 | 3타: 양팔 내려찍기 | Boss1_OverheadSlam_00 ~ 07 |
| 6 | 부스터 돌진 | Boss1_BoosterDash_00 ~ 07 |
| 7 | 후방 미사일 | Boss1_RearMissile_00 ~ 07 |
| 8 | 주기적 미사일 난사 | Boss1_MissileBarrage_00 ~ 07 |

본체가 이동하는 동작도 셀 안에서 제자리로 구성했습니다. 실제 전진과 돌진 거리는 게임 오브젝트 이동으로 제어합니다.
공격 포즈의 초기 구간은 예고, 중간 구간은 공격, 마지막 구간은 복귀에 사용합니다.
내려찍기의 양팔을 든 포즈는 02~03, 바닥을 찍는 포즈는 04~05입니다.

## Support 시트

파일: Sprites/Boss1_Support_v1.png
해상도: 2048 × 1024 px, 8열 × 4행, 총 32프레임.

| 위에서부터 행 | 동작 | 스프라이트 이름 |
| --- | --- | --- |
| 1 | 피격 후 복귀 | Boss1_Hit_00 ~ 07 |
| 2 | 사망 및 쓰러진 상태 | Boss1_Death_00 ~ 07 |
| 3 | 미사일 비행 / 분사 불꽃 | Boss1_MissileFlight_00 ~ 07 |
| 4 | 미사일 폭발 / 연기 소멸 | Boss1_MissileExplosion_00 ~ 07 |

Death의 07은 쓰러진 상태로 유지합니다.
미사일은 위를 향해 그려져 있으므로 발사 방향에 맞게 회전합니다.
비행과 폭발 이펙트는 본체와 별도의 SpriteRenderer에서 재생합니다.
특히 2페이즈의 조준 고정 미사일은 본체 근접 동작을 멈추지 않고 별도로 표시합니다.

## 기획에 맞춘 재생

이미지는 동작별 포즈이며, Boss1Controller가 기획서의 예고·판정·후딜에 맞춰 각 포즈를 재생합니다.
실제 전투 프리팹은 Assets/Prefabs/Boss1.prefab입니다.

- 하단 휘두르기: 예고 0.65초, 판정 0.15초
- 중앙 펀치: 예고 0.75초, 판정 0.15초
- 내려찍기: 예고 0.85초, 판정 0.20초, 후딜 1.30초
- 돌진: 예고 0.85초, 이동 최대 0.55초, 제동 1.40초
- 후방 미사일: 예고 0.8초, 비행 약 0.6초, 후딜 1.0초
- 난사: 준비 1.0초, 2발씩 3묶음. 발사 포즈 구간을 묶음 간격 0.6초에 맞춰 반복하고 마지막에 1.5초 냉각합니다.
- 난사 반복: 전투 시작 20초 후 첫 사용 예약, 이후 후딜 종료 후 20초마다 재예약하는 테스트 값입니다.
- 조준 고정 미사일: 조준 추적 0.9초, 고정 후 0.6초에 폭발. 본체와 별도로 6초 간격으로 시작합니다.

현재 구성은 2페이즈 공통 본체를 사용합니다. 기존 3페이즈 전용 강화 동작은 추가하지 않았습니다.
기획서: https://docs.google.com/document/d/1Tu8DF-FWIpEfTEjQ8aPzSX1BByPHi8ggqBuXXy6t9Cg

## 포함 파일과 확인 범위

- PNG 2장: 실제 RGBA 투명 배경, 라벨과 격자선 없음
- PNG .meta 2개: 이름이 지정된 96개 SpriteRect와 피벗
- boss1-sprites.json: 행, 열, 프레임 이름, 좌표, 피벗, 원본 추출 위치
- 프레임 수, 빈 셀, 해상도, 셀 간격, 알파 채널 및 포즈 잘림을 확인했습니다.
- 모든 프레임에서 알파 32 이상의 본체/이펙트와 셀 경계 사이에 최소 14 px가 있습니다.
- 원본 생성 이미지, 컨셉아트, 프롬프트, 검증 기록은 output/imagegen/boss1-v1에 보관했습니다.
