# 타격감 튜닝

플레이 장면은 `Assets/Scenes/Main.unity`입니다. 플레이어와 더미 프리팹에 기본값을 연결했습니다.

## 현재 값

| 위치 | 항목 | 기본값 |
| --- | --- | --- |
| PlayerAttack | 1·2타 준비 / 활성 / 후딜 | 125 / 125 / 125ms 유지 |
| PlayerAttack | 3타 준비 / 활성 / 후딜 | 375 / 125 / 125ms 유지, 공중은 착지까지 연장 |
| PlayerAttack | 접촉 판정 지연 | 휘두르기 시작 후 기본타 25ms, 3타 20ms |
| PlayerAttack | 다음 공격 예약 | 후딜 마지막 100ms 또는 명중 히트스탑 중 한 번 |
| PlayerAttack | C 슬라이드 캔슬 | 선딜레이·후딜레이에서 가능, 타격 활성 중에는 불가 |
| PlayerChordStrike | A스킬 쿨타임 | 발동 시작부터 5초, 인스펙터의 Cooldown Time에서 조정 |

히트스탑은 기본타의 연결감을 살리도록 기존 40ms에서 35ms로 줄이고, 긴 준비 동작을 가진 3타의 보상을 강조하도록 기존 70ms에서 85ms로 늘렸습니다. 이는 튜닝 출발값이며, 실제 정지 체감은 렌더링 프레임 간격에 따라 달라질 수 있습니다.

더미의 반동은 고정물의 시각적 넉백입니다. 발밑 피벗 아래의 Visual만 변형하며, 루트 위치·피격 판정·체력바는 움직이지 않습니다. 향후 이동 가능한 적은 `AttackHit`의 방향·강도를 받아 실제 물리 넉백을 별도로 구현할 수 있습니다.

접촉 지연은 스프라이트를 교체할 때 함께 조정해야 합니다. 명중 이펙트는 적의 공격자 쪽 표면에 표시하며, 착지 먼지는 명중 여부와 별개입니다. 공중에서 이미 맞힌 적에게 착지 피해를 중복 적용하지 않습니다.

## 플레이 확인 순서

1. 더미 옆에서 1·2타: 기타의 접촉 자세, 타격음, 피격 반동이 같은 순간에 읽히는지 확인합니다.
2. 공격 준비 중, 후딜 끝, 히트스탑 중 각각 다음 공격을 누릅니다. 준비 중 입력은 무시하고, 후딜 끝과 히트스탑에서는 한 번만 예약합니다.
3. 오른쪽·왼쪽에서 공격합니다. 더미 몸통은 타격 방향으로 젖혀지고 체력바와 판정은 유지되어야 합니다.
4. 제자리 3타와 전진 3타를 비교합니다. 두 경우 모두 상승·낙하·착지 충격이 발생해야 합니다.
5. 지상에서 시작한 3타의 도약·내려찍기로 더미를 맞힙니다. 착지 먼지와 카메라 충격은 발생하되 피해는 25 한 번이어야 합니다.
6. 후딜 슬라이드 캔슬 후 다음 공격을 누릅니다. 예약 입력은 취소되고 콤보 순서는 유지되어야 합니다.

먼저 반동·접촉 타이밍을 조정하고, 카메라 진폭과 보조음 볼륨은 마지막에 맞추는 것을 권합니다. 카메라 흔들림은 세 진폭을 모두 0으로 설정해 비교할 수 있습니다.

## 공중·방향 공격 및 키 설정

- ← / → 이동, ↓ 앉기, Z 점프, X 공격, C 슬라이드. 기존 코드 스트라이크는 A를 유지합니다.
- C 슬라이드는 일반·방향 공격의 선딜레이와 후딜레이를 캔슬합니다. 지상·코요테 타임과 슬라이드 쿨타임 조건을 만족해야 하며, 캔슬 시 다음 공격 예약을 지우고 기존 콤보 순서를 유지합니다. 타격 활성 중 누르고 있는 C는 후딜레이까지 대기합니다.
- A 코드 스트라이크는 실제 발동부터 5초 후 다시 사용할 수 있습니다. 쿨타임 중 누른 A는 예약되지 않으며, 쿨타임은 히트스탑·일시정지 중 함께 멈춥니다.
- 일반 공격은 지상에서 1 → 2 → 3타, 공중에서 1 → 2타를 반복합니다. 기존 콤보 유지 시간 안에서는 이륙·착지해도 순서를 이어가며, 공중 2타 후 착지하면 다음 공격은 지상 3타입니다.
- ↑ + X는 지상·공중에서 윗공격, ↓ + X는 공중에서만 아랫공격입니다. 지상 ↓ + X는 일반 공격으로 처리합니다.
- 방향 공격은 일반 콤보를 초기화하므로 다음 일반 공격은 1타입니다. 방향 입력은 공격 키를 누른 순간 저장하며 기존 후딜·히트스탑 입력 예약을 사용합니다.
- 공중 공격 중에도 좌우 이동과 기존 점프·낙하를 유지합니다. 방향 공격은 상승·급강하·반동을 추가하지 않습니다. 지상에서 시작한 일반 3타의 도약·내려찍기는 유지합니다.
- ↓를 누르는 동안 지상에서 앉고 좌우 이동을 멈춥니다. 키를 떼면 일어나며, 머리 위 공간이 부족하면 앉은 상태를 유지합니다.

`Assets/Prefabs/Player.prefab`의 `AttackHitboxes/UpperAttack`, `AttackHitboxes/DownAttack`에서 Box Collider 2D의 Offset / Size 또는 Edit Collider로 범위를 조정합니다. 초기 Offset은 (0, 1) / (0, -1), Size는 둘 다 (1.3, 1.1)입니다. `PlayerAttack`의 Up / Down Attack Timing과 Attack Damage에서 시간·피해량을 조절합니다. 윗공격과 아랫공격은 준비된 `PlayerUpperAttack`, `PlayerDownAttack` 애니메이션을 사용합니다.

`./Tools/ValidateRhythmGauge.ps1`은 기존 리듬·지상 3타 검증과 함께 공중 콤보, 지상·공중 연결, 방향 공격, 단일 명중, 애니메이션 복귀, 실제 키 입력과 앉기·점프·슬라이드를 검증합니다.

## 자동 검증

프로젝트 루트에서 `./Tools/ValidateCombatFeel.ps1`을 실행합니다. 설치된 동일 Unity 버전으로 `Temp/CombatFeelValidation`에 복사본을 만들고, 헤드리스 Play 모드에서 검증합니다. 열려 있는 원본 프로젝트와 씬에는 접근하지 않습니다.

로그: `Temp/CombatFeelValidation/validation.log`
