# 보스 1 씬 진입

- 씬: `Assets/Scenes/Boss01_Arena.unity`. 로비 의뢰 게시판에서 클릭 또는 위 방향키로 진입한다.
- 2026-11-25 사용자 요청에 따라 첨부 그림의 공장 벽·창문·철골 기둥·조명·청록 벽·수평 바닥을 새 배경으로 제작해 배치했다. 기존 타일 바닥은 그림만 숨기고 물리 콜라이더는 유지한다.
- 플레이어는 왼쪽 **(-12, 0.742)**에서 시작한다. 전체 이동 범위는 **X -24~28**이며, 양 끝에 실제 벽 콜라이더가 있다. `FactoryEnvironment`가 배경과 훈련 구역을 묶는다.
- 스폰 왼쪽 **X -20 / -17.5**에 기존 `TrainingDummy` 프리팹 2개를 배치했다. 사용자가 **기존 노란 캐릭터형 허수아비 유지**를 선택했다. 바닥에 발을 맞추고 기존 피격·체력·재생성·리듬 획득을 유지한다. 배경에 그려진 장식이 아니라 실제 타격 대상이다.
- **X 6**에 도착하면 보스가 **(12, 0.02)**의 위 **16유닛**에서 중력으로 낙하한다. 보스는 진입 전에는 비활성 상태라 체력 HUD와 공격도 나타나지 않는다.
- 등장 시작과 동시에 **X -4~24**의 전투 구역이 닫힌다. 양쪽 2D 콜라이더는 높이 24로 점프·슬라이드 탈출을 막는다. 사용자 선택에 따라 실제 철제 셔터 스프라이트를 약 **0.5초** 동안 내려 닫으며 카메라는 셔터 바깥 면까지 보여 준다.
- 낙하 중에는 공격과 피해 수신을 정지한다. 착지 후 **0.6초**를 기다린 다음 기존 전투 컴포넌트를 복구한다. 등장 낙하에는 공격 판정이 없다.
- `Boss1SlamSpriteVisual`은 전투 제어가 꺼진 등장 중에도 실제 Idle 원화를 보여 준다. 임시 도형 몸체는 숨기되 기존 패턴 예고·미사일 표시는 유지한다.
- 리듬은 **등장 시작**과 **착지 후 전투 시작 직전** 두 번 `ResetGauge()`로 0으로 만든다. `LifeVersion`도 바뀌어 이전에 발사한 음표의 리듬 보상까지 무효화한다. 허수아비에서 채운 리듬이나 등장 중 획득한 리듬을 보스전에 가져갈 수 없다.
- 보스 점프 패턴의 착지 범위도 **X -4~24**에 맞췄다. 기존 패턴 수치와 공통 프리팹은 유지한다.
- **보스를 처치하면** 양쪽 셔터가 천장으로 다시 올라가고 구역 제한을 해제한다. 카메라 범위도 원래대로 복구한다. 자동 로비 복귀는 아직 없다.
- 카메라는 Orthographic Size **8**, 높이 **4.5**, 오른쪽 선행 거리 **1**이다. 시작 화면에 두 허수아비와 스폰을 함께 담고, 전투 중에도 공장 벽과 셔터를 볼 수 있게 했다.
- `Boss1Encounter` 오브젝트의 인스펙터에서 등장 지점·착지 지점·게이트·카메라와 낙하 높이·착지 대기를 조정한다. 선택 시 노란 선은 진입 지점, 초록 선은 낙하 경로이다. 위치 표식은 런타임에 표시하지 않는다.
- 기본 Play 모드 검증: 로비에서 Play 시작 후 `unity command script run -- --file Tools/Boss1EncounterValidation.cs --entry Boss1EncounterValidation.Run`. 구역 밖 입력, 게시판 진입, 두 허수아비 실제 타격, 리듬 초기화 두 시점, 낙하 원화, 셔터 애니메이션·충돌·처치 후 해제를 확인한다. 전체 패턴·전투 밸런스 검사는 별도로 진행한다.
- 최종 검증: **기본 Play 검사 20개 통과**, Unity 재컴파일 오류·경고 0개, 에셋 참조 검사 **2,452개 파일에서 오류·경고 0개**. 자동 입력의 게임 뷰 포커스 설정은 검사 후 원래 값으로 복구한다. 열린 셔터는 천장 안으로 올라간 후 숨긴다.

## 배경·셔터 에셋 출처와 기술 설정

- `Assets/Environment/Boss01/FactoryArenaBackdrop.png`: **2172×724**, 불투명 RGB. 스프라이트 피벗은 왼쪽 바닥 기준 **(0, 164/724)**, 월드 폭 **52**이며 발밑 기준선은 **Y 0**이다.
- `Assets/Environment/Boss01/FactoryShutter.png`: **724×2172**, 실제 알파가 있는 RGBA. 철제 슬랫·볼트·하단 안전 무늬로 구성된 별도 패널이며 코드 도형으로 대체하지 않는다.
- 두 이미지 모두 내장 **image_gen**으로 새로 생성했다. 입력은 사용자가 제공한 배치 그림과 프로젝트의 기존 `LobbyBackdrop.png`이다. 원본은 보존했다. 필터 Point, 밉맵 없음, PPU 100, 무압축, 최대 크기 4096으로 임포트한다.
- 셔터는 `ArenaShutter`가 패널만 위아래로 움직인다. 게이트 콜라이더가 닫히면 내려오고 열리면 올라간다. 인스펙터에서 이동 거리 **13**, 속도 **26유닛/초**를 조정할 수 있다.
