- 씬: `Assets/Scenes/Boss01_Arena.unity`. 로비 의뢰 게시판에서 클릭 또는 위 방향키로 진입한다.
- 2026-11-25 사용자 요청에 따라 첨부 그림의 공장 벽·창문·철골 기둥·조명·청록 벽·수평 바닥을 새 배경으로 제작해 배치했다. 기존 타일 바닥은 그림만 숨기고 물리 콜라이더는 유지한다.
- 플레이어는 왼쪽 **(-12, 0.742)**에서 시작한다. 전체 이동 범위는 **X -24~28**이며, 양 끝에 실제 벽 콜라이더가 있다. `FactoryEnvironment`가 배경과 훈련 구역을 묶는다.
- 스폰 왼쪽 **X -20 / -17.5**에 기존 `TrainingDummy` 프리팹 2개를 배치했다. 사용자가 **기존 노란 캐릭터형 허수아비 유지**를 선택했다. 바닥에 발을 맞추고 기존 피격·체력·재생성·리듬 획득을 유지한다. 배경에 그려진 장식이 아니라 실제 타격 대상이다.
- **X 6**에 도착하면 **메가 메카트론 JT8-3**의 등장 연출이 시작된다. **0.35초** 동안 낙하 그림자와 검은 띠로 예고한 뒤 **(12, 0.02)**의 위 **16유닛**에서 중력으로 낙하한다. 보스는 진입 전에는 비활성 상태라 체력 HUD와 공격도 나타나지 않는다.
- 등장 시작과 동시에 **X -4~24**의 전투 구역이 닫힌다. 양쪽 2D 콜라이더는 높이 24로 점프·슬라이드 탈출을 막는다. 사용자 선택에 따라 실제 철제 셔터 스프라이트를 약 **0.5초** 동안 내려 닫으며 카메라는 셔터 바깥 면까지 보여 준다.
- 등장 중에는 플레이어 이동·공격·코드 스트라이크와 보스 공격·피해 수신을 정지하고 플레이어 HUD도 숨긴다. 등장 낙하에는 공격 판정이 없다. 착지 시 **0.08초 히트스탑**, 아래로 찍히는 **0.4초 쉐이크**, 좌우 먼지·충격파와 저음 착지음을 재생한다.
- 화면 위아래 각각 **7.5%**의 검은 띠, 보스 쪽으로 **10% 줌인**, 낙하 중의 약한 진동을 적용한다. 착지와 함께 작은 이명 **중장갑 전투 병기**와 큰 이름을 **1.05초** 동안 공개하고 원화에 짧은 충격 흡수 동작을 준다. 이름은 프로젝트에 포함한 **Boss Title KR** 폰트로 표시한다.
- 첫 등장에서는 착지 직전 약 **0.35초** 동안 **0.6배속** 슬로우를 적용한다. 남은 낙하 거리를 계산해 시작하며, 착지하면 슬로우를 끝내고 기존 **0.08초 히트스탑**을 재생한 뒤 원래 속도로 돌아온다. 재도전에서는 이 슬로우를 생략한다.
- 이름 공개 뒤 **0.6초** 동안 검은 띠·줌을 풀고 짧은 기타 코드로 전투 시작을 알린다. **조작을 해제한 뒤** 보스 체력바가 **0.8초** 동안 부드럽게 차오르며, 충전 중에도 보스 공격과 피해 수신이 가능하다. 충전 중 받은 피해는 실제 체력과 피해 잔상에 유지되며 충전 완료가 체력을 회복시키지 않는다. 충전은 히트스탑·일시정지 중 멈춘다. 재생 중인 루프 오디오는 연출 동안 원래 음량의 **25%**로 줄였다 복구한다. 현재 씬에는 별도의 BGM이 없다.
- 보스 앰프 체력바는 **주황색 실제 체력 + 뒤쪽 밝은색 피해 잔상** 두 겹이다. 실제 체력은 피격 즉시 감소하고, 잔상은 **0.25초 대기 후 0.4초** 동안 따라 줄어든다. 연속 피격은 현재 잔상 길이를 유지한 채 대기 시간을 다시 시작한다. 히트스탑·일시정지 중 잔상도 멈춘다.
- 한 Play 세션에서 이미 본 보스는 재진입할 때 예고 **0.15초**, 이름 공개 **0.35초**로 줄인다. 씬 전환이나 `Boss1Encounter` 비활성화로 연출이 중단되면 조작·음량·카메라·셔터를 복구한다.
- `Boss1SlamSpriteVisual`은 전투 제어가 꺼진 등장 중에도 실제 Idle 원화를 보여 준다. 임시 도형 몸체는 숨기되 기존 패턴 예고·미사일 표시는 유지한다.
- 리듬은 **등장 시작**과 **착지 후 전투 시작 직전** 두 번 `ResetGauge()`로 0으로 만든다. `LifeVersion`도 바뀌어 이전에 발사한 음표의 리듬 보상까지 무효화한다. 허수아비에서 채운 리듬이나 등장 중 획득한 리듬을 보스전에 가져갈 수 없다.
- 보스 점프 패턴의 착지 범위도 **X -4~24**에 맞췄다. 기존 패턴 수치와 공통 프리팹은 유지한다.
- **보스를 처치하면** 양쪽 셔터가 천장으로 다시 올라가고 구역 제한을 해제한다. 카메라 범위도 원래대로 복구한다. 자동 로비 복귀는 아직 없다.
- 카메라는 Orthographic Size **8**, 높이 **4.5**, 오른쪽 선행 거리 **1**이다. 시작 화면에 두 허수아비와 스폰을 함께 담고, 전투 중에도 공장 벽과 셔터를 볼 수 있게 했다.
- `Boss1Encounter` 오브젝트의 인스펙터에서 등장 지점·착지 지점·게이트·카메라와 낙하 높이·화면 마무리 시간·체력바 충전 시간(`Health Fill Duration`)을 조정한다. 같은 오브젝트의 `Boss1EntrancePresentation`에서 예고·이름 표시 시간, 첫 등장 슬로우 배율·시간(`Slow Motion Scale / Duration`), 검은 띠 높이, 줌·착지 진동 강도와 기존 사운드·먼지 프리팹을 조정한다. 보스의 `Boss1Health`에서 피해 잔상의 대기·감소 시간과 색을 조정한다. 선택 시 노란 선은 진입 지점, 초록 선은 낙하 경로이다. 위치 표식은 런타임에 표시하지 않는다.
