기준: [보스 1 기획서](../기획문서/보스%201%20기획서.md) "외형"·"패턴 상세", [보스 1 구현 스펙](보스%201%20구현%20스펙.md)
상태: **초안 (2026-11-12)**. 시드 이미지 승인 전. 에셋 목록은 [`보스 1 에셋 목록.json`](보스%201%20에셋%20목록.json).

## 1. 게임 프레임

| 항목 | 값 |
|---|---|
| 엔진 | Unity 6000.3.25f1, URP 2D, SpriteRenderer |
| 시점 | 2D 사이드뷰, 오른쪽을 보는 그림 하나로 그리고 좌우는 뒤집어서 쓴다 |
| 크기 | 서 있는 키 **3.5H = 4.6유닛** (1H = 1.31유닛, 플레이어 키의 3.5배) |
| 기존 아트 | 좀비(`Characters/Zombie`)만 완성 아트. 외곽선이 있는 2D 셀 셰이딩 일러스트, 1024px 프레임, PPU 256, 발밑 피벗. 플레이어는 아직 실루엣 플레이스홀더 |

## 2. 비주얼 시스템

- **모양 언어**: 무겁고 각진 블록. 상체가 크고 하체가 짧은 역삼각형 체형. 둥근 모서리 없이 모따기한 장갑판.
- **실루엣 우선순위** (작게 봐도 읽혀야 하는 순서)
  1. 몸통만 한 **거대한 양 주먹**: 공격 방향과 높이를 알려 주는 핵심
  2. 등에서 머리 위로 솟은 **붉은 미사일 발사기** 상자: 미사일 패턴의 예고 부위
  3. 등 아래쪽의 **부스터 노즐 2개**: 이동형 예고의 불꽃이 나오는 곳
  4. 작은 머리와 **붉은 단안 센서**
- **명암 구조**: 몸체는 어두운 값(전체의 70% 이상을 어두운 회청색)으로 두고, 발광부(청록 회로·붉은 센서·부스터 불꽃)만 밝게 해서 예고 부위가 바로 눈에 띄게 한다.
- **팔레트 역할**

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 장갑 기본 | `#2A2F3A` | 몸 대부분 |
| 장갑 그림자 | `#161A22` | 판 사이 틈, 그늘 |
| 장갑 하이라이트 | `#5B6577` | 모서리 반사 |
| 회로 발광 | `#2EF2E0` | 장갑 틈의 회로선, 관절 |
| 센서·발사기 | `#FF2E3C` | 단안 센서, 미사일 발사기 외장 |
| 부스터 불꽃 | `#FF8A2A` → `#FFE07A` | 부스터 점화(이펙트) |
| 외곽선 | `#0B0D12` | 2~3px 굵은 외곽선 |

- **재질**: 무광 금속 장갑, 긁힘과 리벳은 적게. 발광부에만 은은한 빛번짐.
- **외곽선**: 좀비와 같은 굵은 어두운 외곽선 + 2단 셀 셰이딩 (그라데이션 최소화).
- **조명**: 왼쪽 위에서 오는 빛. 모든 프레임에서 같은 방향.
- **디테일 밀도**: 주먹 > 발사기 > 몸통 > 다리 순. 다리는 단순하게 둔다.
- **동작 성격**: 평소엔 묵직하고 느린 예비동작, 부스터가 켜지는 순간만 급가속. 기획서의 "느림 ↔ 빠름" 대비를 보스도 똑같이 보여 준다.
- **넣지 않는 것**: 글자, 로고, 마크, 사람 얼굴, 날개, 망토, 무기(칼·총), 배경.

## 3. 제작 방식 (제안)

**컷아웃 리그 방식을 권장한다.** 시드 콘셉트 1장을 AI로 만들어 승인받은 뒤, 같은 그림을 기준으로 부위(머리·몸통·상완·하완·주먹 ×2·다리·발사기·부스터)를 분리한다. 그다음 프로젝트에 이미 있는 **PSD Importer + 2D Animation**으로 뼈대를 잡고 Unity에서 직접 애니메이션을 만든다.

- 로봇은 관절이 단단한 부품 구조라 컷아웃 리그와 잘 맞는다.
- 프레임마다 AI로 그리면 장갑 디테일·비율이 프레임 사이에 흔들린다. 영상→스프라이트 시트 모델도 같은 문제가 있다.
- 예고 시간(0.35~1.0초)을 플레이테스트로 계속 바꿔야 하는데, 리그는 키프레임 시간만 옮기면 된다. 2페이즈 예고 ×0.8도 같은 클립의 재생 속도로 처리할 수 있다.
- 텍스처는 부위 아틀라스 1장으로 끝나서, 프레임 시트 수십 장보다 메모리가 훨씬 작다.

**부스터 불꽃·미사일·폭발·충격파는 본체와 분리한 이펙트**로 만든다. 부스터는 돌진·도약·백스텝·부스트 스텝에 공통으로 쓰니까, 등의 소켓에 붙는 불꽃 하나를 세기(예열·분사·지속)만 바꿔 재사용한다. 경고 원·조준선은 코드에서 그린다(현재 구현 스펙과 같음).

## 4. 기술 계약

| 항목 | 값 |
|---|---|
| 시드 콘셉트 | 1024×1024, 투명 배경, 오른쪽을 보는 측면 대기 자세, 발이 캔버스 아래에서 64px 위 |
| 부위 아틀라스 | 2048×2048 이하 PSB 1장(레이어 = 부위), 투명 배경 |
| PPU | 서 있는 키가 4.6유닛이 되게 맞춘다. 시드 키 약 740px이면 **PPU 160** |
| 피벗 | 발밑 가운데 (bottom-center) |
| 필터·압축 | Bilinear, 밉맵 끔, 압축 Normal Quality (좀비와 같은 일러스트 계열이라 Point 아님) |
| 색 공간 | sRGB (색 텍스처만) |
| 폴더 | `Assets/Characters/Boss1/` 아래 `Concept/`, `Rig/`, `Animations/`, `Effects/` |
| 이름 | `Boss1_<부위 또는 동작>` (예: `Boss1_Punch`, `Boss1_FX_BoosterBurst`) |

## 5. 애니메이션 목록 (패턴 타이밍 기준)

시간은 1페이즈 값. 2페이즈는 예고 구간만 0.8배로 재생한다. "예고 포즈"는 기획서의 예고 방식(본체 = 팔·몸 준비, 이동형 = 부스터 점화, 미사일 = 발사기 동작)을 따른다.

| 클립 | 구간 (초) | 핵심 포즈 | 부스터 |
|---|---|---|---|
| `Idle` | 루프 | 주먹을 바닥 가까이 늘어뜨리고 어깨가 천천히 오르내림 | 꺼짐 |
| `BoostStep` | 준비 0.2 → 이동 0.2 → 정지 0.3 | 살짝 앞으로 숙임 → 미끄러지듯 전진 → 버티기 | 짧은 분사 |
| `Combo1_Sweep` | 예고 0.65 → 판정 0.15 → 틈 0.35 | 팔을 뒤로 크게 빼고 낮은 자세 → 지면 가까이 수평으로 휩쓸기 → 팔 거둬들이기 | 꺼짐 |
| `Combo2_Punch` | 예고 0.75 → 판정 0.15 → 틈 0.35 | 반대 팔을 어깨 뒤로 당김 → 가슴 높이로 곧게 뻗기. 주먹 하단이 슬라이드 높이보다 위에 보이게 | 꺼짐 |
| `Combo3_Slam` | 회전 0.25 → 예고 0.60 → 판정 0.20 → 후딜 0.55 | 몸을 돌림 → 양팔을 머리 위로 → 바닥 내려찍기 → 주먹이 박힌 채 빼내기 | 꺼짐 |
| `Dash` | 예고 0.85 → 이동 ≤0.55 → 제동 0.60 | 몸을 낮게 웅크림(플레이어가 위로 넘을 수 있는 높이) → 어깨를 앞세운 돌진 → 발로 미끄러지며 제동 | 예열 → 최대 분사 |
| `Leap` | 웅크림 0.8 → 체공 0.7 → 착지 0.15 → 후딜 0.55 | 깊게 웅크림 → 공중에서 양 주먹을 모음 → 주먹으로 착지 → 주먹이 바닥에 박혀 있음 | 예열 → 이륙 분사 → 꺼짐 |
| `Backstep` | 분사 0.35 → 이동 0.3 → 대기 0.3 | 상체를 뒤로 젖히며 밀려남 → 착지 | 앞쪽으로 역분사 |
| `RearMissile` | 예고 0.8 → 발사 → 복귀 0.5 | 발사기가 뒤쪽으로 젖혀짐 → 2발 발사 반동 → 원위치 | 꺼짐 |
| `Barrage` | 준비 1.0 → 발사 루프 6.0 → 냉각 0.6 | 양팔을 벌리고 발사기 덮개를 엶 → 반동 루프 → 발사기에서 김이 남 | 꺼짐 |
| `AimMissile` | 본체와 별도 | 머리 옆 소형 발사구가 열려 있는 부품 상태만 (본체 동작은 그대로 둔다) | — |
| `PhaseShift` | 선택 | 센서가 더 밝아지고 회로가 깜빡임 (색 변화로 처리 가능) | — |
| `Death` | 1.5 내외 | 무릎 꿇고 앞으로 쓰러짐, 회로 소등 | 꺼짐 |

피격 반응은 셰이더 플래시로 처리하고 별도 클립을 만들지 않는다 (기존 `HitFlashSpriteEffect`와 같음).

## 6. 이펙트 목록

| 이펙트 | 쓰는 곳 | 비고 |
|---|---|---|
| 부스터 불꽃 (예열·분사·지속) | 돌진·도약·백스텝·부스트 스텝 | 등 소켓에 붙는 공용 이펙트. 예열은 노즐 안에 불꽃이 모이는 모양 |

| 착지 먼지·주먹 충격 | 3타 내려찍기, 도약 착지 | |
| 경고 원·조준선·착지 그림자 | 미사일·도약 | 코드에서 그린다 (아트 없음) |

## 7. 진행 순서

이미지 생성은 ChatGPT(GPT Image)에서 한다. 단계별 프롬프트는 [보스 1 GPT 프롬프트](보스%201%20GPT%20프롬프트.md)에 있다.
(Unity AI 생성은 2026-11-12 기준 조직에 구독이 없어서 쓰지 않는다.)

1. **시드 콘셉트** 후보 3장 생성 → 하나를 승인 (게임 화면 크기에서 플레이어와 함께 비교)
2. 승인한 시드 기준으로 부위 분리 → PSB 정리
3. 2D Animation으로 뼈대 → 애니메이션 클립 (5장 목록)
4. 이펙트 제작
5. 게임 안에서 원래 크기로 확인 → 에셋 목록의 검수 항목 체크

## 8. 출처 기록
