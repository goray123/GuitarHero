# 타격감 튜닝

플레이 장면은 `Assets/Scenes/Main.unity`입니다. 플레이어와 더미 프리팹에 기본값을 연결했습니다.

## 현재 값

| 위치 | 항목 | 기본값 |
| --- | --- | --- |
| PlayerAttack | 1·2타 준비 / 활성 / 후딜 | 125 / 125 / 125ms 유지 |
| PlayerAttack | 3타 준비 / 활성 / 후딜 | 375 / 125 / 125ms 유지, 공중은 착지까지 연장 |
| PlayerAttack | 접촉 판정 지연 | 휘두르기 시작 후 기본타 25ms, 3타 20ms |
| PlayerAttack | 다음 공격 예약 | 후딜 마지막 100ms 또는 명중 히트스탑 중 한 번 |
| PlayerAttack | 기본타 전진 | 0.8유닛, 준비 후반부터 휘두르기 초반까지 가감속 |
| PlayerAttack | 3타 상승 | 방향 입력과 무관하게 0.6유닛, 방향 입력 시 가로 전진 |
| PlayerHitStop | 기본타 / 3타 | 35 / 85ms |
| TrainingDummy | 기본타 / 3타 반동 | 가로 0.08 / 0.2유닛, 기울기 5 / 13도 |
| TrainingDummy | 반동 복귀 | 0.22 / 0.34초, 내려찍기는 몸통 압축 |
| PlayerHitCameraShake | 기본타 / 3타 / 착지 | 0.025 / 0.055 / 0.065유닛, 0.14초 감쇠 |
| PlayerHitAudio | 스윙 / 기타 잔향 / 착지 보조음 | 볼륨 0.12 / 0.18 / 0.3 |

히트스탑은 기본타의 연결감을 살리도록 기존 40ms에서 35ms로 줄이고, 긴 준비 동작을 가진 3타의 보상을 강조하도록 기존 70ms에서 85ms로 늘렸습니다. 이는 튜닝 출발값이며, 실제 정지 체감은 렌더링 프레임 간격에 따라 달라질 수 있습니다.

더미의 반동은 고정물의 시각적 넉백입니다. 발밑 피벗 아래의 Visual만 변형하며, 루트 위치·피격 판정·체력바는 움직이지 않습니다. 향후 이동 가능한 적은 `AttackHit`의 방향·강도를 받아 실제 물리 넉백을 별도로 구현할 수 있습니다.

접촉 지연은 스프라이트를 교체할 때 함께 조정해야 합니다. 명중 이펙트는 적의 공격자 쪽 표면에 표시하며, 착지 먼지는 명중 여부와 별개입니다. 공중에서 이미 맞힌 적에게 착지 피해를 중복 적용하지 않습니다.

## 플레이 확인 순서

1. 더미 옆에서 1·2타: 기타의 접촉 자세, 타격음, 피격 반동이 같은 순간에 읽히는지 확인합니다.
2. 공격 준비 중, 후딜 끝, 히트스탑 중 각각 다음 공격을 누릅니다. 준비 중 입력은 무시하고, 후딜 끝과 히트스탑에서는 한 번만 예약합니다.
3. 오른쪽·왼쪽에서 공격합니다. 더미 몸통은 타격 방향으로 젖혀지고 체력바와 판정은 유지되어야 합니다.
4. 제자리 3타와 전진 3타를 비교합니다. 두 경우 모두 상승·낙하·착지 충격이 발생해야 합니다.
5. 더미를 공중 3타로 맞힙니다. 착지 먼지와 카메라 충격은 발생하되 피해는 25 한 번이어야 합니다.
6. 후딜 슬라이드 캔슬 후 다음 공격을 누릅니다. 예약 입력은 취소되고 콤보 순서는 유지되어야 합니다.

먼저 반동·접촉 타이밍을 조정하고, 카메라 진폭과 보조음 볼륨은 마지막에 맞추는 것을 권합니다. 카메라 흔들림은 세 진폭을 모두 0으로 설정해 비교할 수 있습니다.

## 자동 검증

프로젝트 루트에서 `./Tools/ValidateCombatFeel.ps1`을 실행합니다. 설치된 동일 Unity 버전으로 `Temp/CombatFeelValidation`에 복사본을 만들고, 헤드리스 Play 모드에서 검증합니다. 열려 있는 원본 프로젝트와 씬에는 접근하지 않습니다.

결과: `Temp/CombatFeelValidation/combat-feel-results.txt`

로그: `Temp/CombatFeelValidation/validation.log`

신규 보조음은 외부 샘플 없이 합성했습니다. 재생성: `./Tools/GenerateCombatAudio.ps1`. 기존 기본 타격음과 3타 타격음은 그대로 사용합니다.
